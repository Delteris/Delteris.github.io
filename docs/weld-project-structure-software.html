One Source of Truth, Two Ways to Build It

Weld project structure software models a fabrication project — its assemblies, parts and the joints between them — so every weld and work entry has a place to live and a traceable path up to the finished piece. A weld project's structure — assemblies, sub-assemblies, parts and the joints that connect them — is the backbone every capture, qualification and audit trail hangs from. Elenchon holds that structure as a single source of truth and lets you author it two ways: an indented tree for detailed, one-off work, or an editable flowchart for standardized, repeatable structures. Edit either view and the other updates instantly — no import, export, or conversion step. It is the sovereign, on-premise alternative to cloud welding software.

Tree ↔ Flowchart

Two Editable Views, One Model

Switch whenever you want — because they are two windows onto the same project, not two copies.

Different projects want different views. Elenchon gives you both, over one underlying structure, so nobody is forced into a layout that doesn't fit the job.

  • Switch views at will: Every project is editable as a Tree or a Flowchart, toggled with one click. Edits in one view appear instantly in the other.
  • Tree view: A clear, left-indented project tree for detailed and bespoke one-off structures such as ships or custom assemblies.
  • Flowchart view: A visual, drag-to-connect editor for standardized, highly repeatable project structures.
  • Repeatable batches: Define an assembly once and deploy identical copies in quantity — welds defined once apply to every copy.
One-Paste Import

BOM Import from Tekla & CAD

Turn an afternoon of data entry into a single paste.

Your bill of materials already exists in someone else's CAD output. Elenchon takes it as-is and builds your project structure from it, without retyping.

  • Copy straight from your BOM: Paste out of Tekla or your CAD package into an Excel-like grid — no special export format required.
  • Automatic column detection: Elenchon detects and maps every field, so material, profile and quantity land where they belong.
  • Structure built in seconds: The paste becomes a full project structure ready to capture against — an afternoon of data entry done in one step.
  • Guided by hand, too: The paste is an accelerator, not the only door — you can always build or adjust the structure manually.
Living Projects

Edit In-Progress Projects Safely

Real projects change — the structure bends without breaking the record.

Fabrication rarely goes exactly to plan. Elenchon lets you evolve a live project while protecting everything already captured against it.

  • Add and remove as you go: Extend an in-progress project by adding nodes, or clear out empty ones, without starting over.
  • Automatic node locking: Any node that already contains captured work is locked and protected, so history can't be silently rewritten.
  • Heat-number propagation: Base material carried in from the BOM lets heat numbers attach and propagate down the tree for full traceability.

Questions & Answers

Project Structure & BOM Import, Answered

How Elenchon builds weld project structure from your BOM, two ways, on your own hardware.

What is weld project structure software?

It is the tool that models a fabrication project — assemblies, parts and the joints between them — so every weld and work entry has a place to live and a traceable path upward to the finished piece. Elenchon runs it on-premise, on hardware you own.

Can I import a BOM from Tekla or CAD?

Yes. Copy your BOM straight out of Tekla or your CAD package and paste it into an Excel-like grid. Elenchon auto-detects the columns, maps every field, and builds the project structure in seconds — no special export format needed.

What is the difference between the tree and flowchart views?

They are two editable windows onto the same project. The tree is a left-indented outline suited to detailed one-off structures; the flowchart is a visual, drag-to-connect editor suited to standardized, repeatable ones. Edit either and the other updates instantly.

Can I edit a project after work has started?

Yes. You can add nodes or remove empty ones on an in-progress project, while any node that already contains captured work is automatically locked and protected — so the structure evolves without rewriting history.

Does it handle repeatable batches and one-offs?

Both. Define an assembly once and deploy identical copies in quantity for batch production, or build a fully bespoke tree for a one-off — welds defined once on a repeated assembly apply to every copy.

How does this fit the wider platform?

The structure is the backbone. Elenchon is full welding management software — the project structure feeds shop-floor capture, the WPS/PQR/WPQ workflow, the weld traceability chain, and much more.
