Every Import Is a Change-Set You Approve

WPS review-and-approval software puts a human sign-off between an imported document and your WPS records: it proposes each edit as current value versus new value, cell by cell, and only the cells you confirm are committed. Auto-updating compliance records from a parser is how quiet errors get in. Elenchon WPS Manager treats every import as a proposal, not an action. The review queue lays out each change as current → new, down to the individual cell; uncertain reads and computed values are shaded for a closer look; you fix anything wrong inline, tick what should apply, and approve. Set the bar where you want it — review everything, review only the uncertain reads, or auto-apply and rely on versioning to undo. And because your records live in the app, an exported register is only ever produced from what you already approved — when you keep your own workbook in the loop, it is patched, never rebuilt.

Current → New, Cell by Cell

See Exactly What Would Change

Not "23 fields updated" — the actual before and after, at the level of a single cell.

A change you can't see is a change you can't trust. The review queue makes every proposed edit legible: the value you have now, the value the import wants to write, and a tick to decide.

  • Current value → new value: Each proposed edit is laid out side by side at the individual cell, so you read exactly what would move and to what.
  • Tick to apply, untick to keep: Apply a cell to write it, or leave it unticked to keep what you had — the decision is per cell, not per document.
  • Correct before you commit: Fix any value inline, or add a row for a field the parser missed, then approve — what lands is what you signed off on, not the parser's raw read.
Attention Where It's Needed

Low-Confidence Reads, Flagged in Amber

The parser tells you what it wasn't sure of, so your review time goes to the cells that matter.

Reviewing every value equally is how the important one gets missed. WPS Manager surfaces its own uncertainty, so a confident read doesn't cost you a second and a doubtful one can't slip past.

  • Uncertain cells shaded amber: Any value the parser wasn't sure of is highlighted and surfaced for a check, directing your eye to exactly where it's needed.
  • Computed values called out: A heat input the app calculated rather than read is flagged the same way — a number you can confirm, never one that appears silently.
  • Confident reads stay quiet: Values the parser is sure of don't clamour for attention, so a large import doesn't drown you in cells that were never in doubt.
Your Register, Your Rules

Set Your Own Approval Bar

Review everything, review only the uncertain, or auto-apply and lean on versioning.

Different shops trust their forms differently. Rather than force one workflow, WPS Manager lets you choose how strict the gate is — and change your mind whenever.

  • Review every value: Nothing lands without a look — the strictest bar, for a register under close audit scrutiny.
  • Review only the uncertain (default): Confident reads apply, and only the flagged cells wait for you — the balance most shops want.
  • Auto-apply and undo: Let imports land automatically and rely on versioning to roll back anything wrong — fastest, backed by the full version history.
The Sheet Never Quietly Drifts

Drift Detection Between Library and Register

If a document changes after its values landed, you're told — and offered a re-sync.

A register goes wrong slowly: a WPS is edited, but the row it fed stays as it was. WPS Manager watches for that gap and closes it deliberately, with your sign-off.

  • Out-of-sync, surfaced: If a WPS is edited after its values already landed, the app flags that the register is out of sync with the library behind it.
  • Re-sync on your say-so: It offers to re-compute the affected rows as a fresh change-set — reviewed and approved like any other, never silently rewritten.
  • Documents and sheet stay tied: The register always traces back to the documents that fed it, so the sheet and the paperwork can't drift apart unnoticed.
Patched, Never Rebuilt

Only Approved Cells Are Written to Your Workbook

Your file stays yours — the app changes the cells you confirmed and nothing else.

The register you keep is your own workbook, and it stays that way. WPS Manager never regenerates your file from a model and hands it back changed — it edits precisely the cells you approved.

  • Surgical patching: The app writes the confirmed cells into your own file and leaves everything else exactly as you had it — formatting, layout and all.
  • Every approval versioned: Each approved change-set produces a new register version, so you can roll back to any earlier snapshot at will (see register versioning).
  • Cleared without a false change: A change-set that only needs a value verified — with nothing actually to alter — is closed with a "mark reviewed", not a hollow approval that writes an identical version.
Questions & Answers

WPS Review & Approval, Answered

How the change-set works, what gets flagged, and what lands in your sheet.

Does an import change my register automatically?

Only if you choose to let it. By default every import queues as a proposed change-set — current value beside new value, cell by cell — and you approve what lands. You can raise the bar to review every value, or lower it to auto-apply and rely on versioning to undo. Only the cells you approve are patched into your own workbook.

How do I know which values to check?

The parser flags its own uncertainty. Any cell it wasn't sure of — or a heat input it computed — is shaded amber and surfaced for review, while confident reads stay quiet, so your attention goes exactly where it's needed.

Can I correct a value during review?

Yes. Fix any value inline, or add a row for a field the parser missed, then approve. What lands is what you signed off on — you're never forced to accept the parser's raw read or reject the whole set.

What happens if a WPS changes after its values landed?

Drift detection catches it: the app tells you the register is out of sync with the library and offers to re-sync the affected rows as a fresh change-set, reviewed and approved like any other — the sheet never quietly drifts from the documents behind it.

Does it rebuild my whole spreadsheet?

No. WPS Manager patches only the approved cells into your own workbook and leaves everything else exactly as you had it. Your file is never regenerated from a model, and every approved change-set is versioned so you can roll back.

What if an import has nothing to change, only something to verify?

It's closed with a "mark reviewed" rather than an approval that would write an identical new version — so a verification-only change-set doesn't leave you stuck between approving a change that isn't there and rejecting a correct read.
