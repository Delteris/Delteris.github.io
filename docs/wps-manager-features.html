Import

Excel & PDF, Read For You

Pull the WPSs you already hold straight into a register. Two purpose-built parsers do the data entry — no re-typing a procedure into someone else's template.

01
  • Excel and PDF, both native: One parser reads Excel WPS workbooks; another reconstructs a PDF form's ruled grid and reads its cells. Process, materials, ranges and pass-by-pass parameters land as structured fields.
  • Language-agnostic: The parser reads a form's structure, not a fixed vocabulary, and matches labels from a language pack — so a form in your language reads without special setup. English and Portuguese ship today; others are added during onboarding.
  • Batch, and classified as it lands: Bring in a whole stack at once — each file sorted into a new WPS, a new revision, or a correction, with revisions grouped from the start.
  • Tuned to your template: Standard ISO 15609-style forms work immediately; during onboarding we tune the parser to your company's exact layout.

Human-Reviewed Edits

Nothing Lands Until You Approve It

A parser is only trustworthy if you can see what it read. Every import queues as a change-set you sign off, value by value.

02
  • See exactly what would change: Each row is a document, a field, and the value read — nothing is written to your register until you confirm it.
  • Low-confidence reads are flagged: Anything the parser wasn't sure of — or a heat input it computed — is shaded amber and surfaced, so your attention goes where it's needed.
  • Verify without leaving: Confirm a computed value from the queue, or open the document in the library to check it against the source first.
  • Set your own bar: Review every value, review only the uncertain ones (the default), or auto-apply and rely on versioning to undo.

Your Register, Visualised & Versioned

Your Own Workbook, Kept Current

The register you keep is your spreadsheet, held as a live grid and backed by a full version history — the master file head office asks for, one click away.

03
  • Visualised, not just stored: Your master sheet opens as a fast, filterable grid — here, 36 rows across 28 columns — instead of a spreadsheet you scroll by hand.
  • Every version kept: Each approved change-set makes a new version. Roll back to any snapshot; the newest is always protected.
  • Export on demand: Produce a clean Excel workbook whenever you need it — or an export bundle (.zip) with the register plus the folder of linked WPS files, so the paperwork travels with the sheet.
  • Re-compute & sync: Pull the latest values from the library into the register in one action, so the sheet never quietly drifts from the documents behind it.

A Library That Reads Your WPSs

Every Field, Down to the Pass Table

Behind every register row is a fully-read document — header fields, the full pass table, materials and consumables, all structured and all searchable.

04
  • Three document types, one home: WPS, pWPS and WPQR each get a tab, each parsed and linkable, each showing a Parsed and Linked status at a glance.
  • The real detail: Header block — standard, base metal, thickness and diameter range, preheat, shielding — plus the full pass table with process, filler class, polarity, current, voltage, travel speed and heat input for every pass.
  • Edit and verify in place: Correct any value or its label and save; a one-click verify clears a low-confidence flag, and computed heat input clears across every pass at once.
  • Filter by what's inside: Narrow by process, material, position and thickness — even by values inside the passes, such as every WPS that runs a 111 root.

The Linked Chain

WPQR and pWPS, Attached to the Procedure

A WPS is qualified by a WPQR, which traces back to a pWPS. The library keeps that chain linked, so from any record you can see exactly what supports it.

05
  • WPQR linked to the WPS it qualifies: A single WPQR can support several procedures — here it's linked to two WPS numbers, picked from the library by number.
  • pWPS linked to the WPQR: Trace each qualification record back to the preliminary WPS behind it — the full pWPS → WPQR → WPS chain, visible and one click apart.
  • Collected data, structured: Qualification standard, process, test date and the rest are read into fields, not left buried in an attachment.
  • Where WPS Manager stops: It attaches, links and displays these records — capturing WPQR results live on the floor is the job of the full Elenchon platform.

Heat Input Helper

Stay Inside the Qualified Window

Heat input is where a good procedure quietly goes out of qualification. The helper computes it live and clamps the controls to the range your PQR qualified.

06
  • Pull straight from a WPS: Load a parsed WPS and its per-region ranges and processes fill in automatically — here, the arc values from MER-WPS-026.
  • Sliders that can't leave the window: Drag current, voltage and travel speed and watch the heat input compute live; the controls clamp to your PQR-qualified range, so an out-of-range result can't be dialled in.
  • Root, fill and cap independently: Each weld region gets its own qualified range and its own live read — green when it's inside the range.
  • Multi-arc aware: Tandem and twin-arc setups sum across heads, the way the standard expects. It's a scratch pad — nothing is saved or written to any sheet.
