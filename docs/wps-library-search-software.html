Manage the Whole Library — In the App, Not in Excel

WPS library software keeps every Welding Procedure Specification, preliminary WPS and WPQR as a structured, searchable record — so you can find, compare, correct and link any procedure by what's inside it, without opening a spreadsheet. The register is the export your auditors and head office ask for; the library is where you actually work. WPS Manager is built so the app is the home for your procedures: each document is fully read, editable in place, and connected to the records that qualify it. Revisions of the same WPS number group themselves; a WPS links to the WPQR that qualifies it, and the pWPS traces back to that WPQR; and the whole collection becomes a database you can question — filtered on the real contents of each form, down to which passes run which process on which side. You manage the library entirely here. Excel export is there for when a register needs to be handed out — not something you have to drop into to get your work done.

Three Document Types, One Home

WPS, pWPS and WPQR — All Fully Read

Every document sits alongside the procedures it relates to, parsed into real detail, not just a filename.

A procedure is more than a file. Each document in the library is read down to its fields, so you're working with structured data you can inspect and correct — not a PDF you have to open and squint at.

  • Three linked types, one library: WPS, preliminary WPS (pWPS) and WPQR each get their own tab, each imported the same way — drop an Excel or PDF, or add a WPQR record by hand.
  • The real detail: Header fields, the full pass table with each pass's side (inside / outside / both) and role (root / fill / cap / backing), base-material parts, filler and consumable, shielding and flux — all extracted and all editable.
  • Add what the parser missed: If a read ever comes up short, add the row yourself — the library never traps you behind a parser's blind spot.
Revisions, Handled

Every Revision of a WPS, Grouped Automatically

Several revisions of one WPS number collapse into a single row with a switcher — newest first.

Revisions are where a filename-based folder falls apart. The library keeps them together and in order, so you always see the current one and can reach the history in a click.

  • One row, all revisions: Multiple revisions of the same WPS number collapse into a single row with an obvious "N revisions" chip and a switcher to move between them, newest first.
  • Classified on import: Each incoming file is sorted for you as a brand-new WPS, a fresh revision of one you hold, or a correction to an existing record.
  • No duplicates in the list: The library stays readable no matter how many revisions accumulate, because they never sprawl into separate rows.
Correct It Right Here

Edit and Verify in Place

Fix a value or its label without leaving the app — and the register keeps up.

Managing a library in the app only works if you can actually change things in it. Every field is editable where it sits, and a correction ripples out to everywhere it should.

  • Value or label, editable: Correct any field's value — or even its label — and save; the label re-titles that column in the register, so your naming stays consistent everywhere.
  • Verify a low-confidence read: A one-click "Verify" clears a flagged cell once you've checked it, and a computed heat input has its own verify that clears the amber across every pass at once.
  • Everything stays in sync: A fix here updates the library detail, the register column titles, and any review badge together — one correction, reflected wherever it belongs.
Filter by What's Inside

Search the Collection by Its Real Contents

Every field is extracted, so you filter on process, material, position — and on the passes themselves.

Because each document is fully parsed, the whole library becomes a database you can question. You ask the questions a QA lead actually asks — and get the answer in a couple of clicks instead of a manual read.

  • Filter by what matters: Narrow by welding process, base or filler material, position, thickness range and more — down to a specific combination of processes, with or without a backing pass.
  • Facets that read the pass table: Filter on the values inside the passes themselves — side, role, process, polarity — as set-membership filters, so "every WPS that runs a 121 root" is one click, not a read-through.
  • Document facets too: Slice by parse state, file type (Excel or PDF), template, link status, or whether a WPS has a linked PQR — the practical filters that answer "what do we actually hold?"
The Whole Qualification Chain

Link a WPS to Its WPQR, and the WPQR Back to Its pWPS

See the records that qualify each procedure, connected and one click apart.

A WPS never stands alone: it's qualified by a WPQR, which traces back to a preliminary WPS. The library keeps that chain connected, so the evidence behind any procedure is always at hand.

  • Smart linking, both directions: Link a WPS to the WPQR that qualifies it, a WPQR to the several WPS it supports, and a pWPS to the WPQR that qualified it — then open any related document in a click.
  • Readable names: Give a WPQR a friendly display name so the chain reads cleanly everywhere it appears, instead of a bare reference.
  • Always know what you hold: One central library means you always know the full set of procedures your shop has qualified — nothing lost in an inbox or a shared drive.

Questions & Answers

WPS Library & Search, Answered

How the library is organised, what you can filter on, and whether you need Excel.

Do I manage my WPSs in the app or in Excel?

In the app. The library is where you work — every WPS, pWPS and WPQR is a structured record you search, filter, edit, verify and link in place. Excel export is there for when a register needs to be handed to your auditors or head office, not something you drop into to get your work done.

Can I filter my WPSs by welding process?

Yes. Because every field is extracted at import, you filter the library by real criteria — process, base and filler material, position, thickness range and more — down to a specific combination of processes, with or without a backing pass, in a couple of clicks.

Can I search on the individual passes?

Yes. Facets read the pass table itself, so you can filter on the values inside the passes — side, role, process, polarity — as set-membership filters. "Every WPS that runs a 121 root" is one click, not a manual read of each document.

How are revisions handled?

Several revisions of the same WPS number collapse into a single row with an "N revisions" chip and a switcher, newest first. Each incoming file is classified on import as a new WPS, a new revision, or a correction — so revisions group correctly and the list stays readable.

Can I correct a parsed field?

Yes, in place. Edit any field's value or its label and save; a label change re-titles that column in the register, and a one-click verify clears a low-confidence flag. Every correction stays in sync across the library, the register titles and the review badge.

Can I link a WPS to its qualification records?

Yes. Link a WPS to the WPQR that qualifies it, a WPQR to the several WPS it supports, and a pWPS to the WPQR that qualified it — then open any of them in a click and see the whole chain together.
